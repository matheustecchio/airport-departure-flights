How it works

Set up, refresh, review

Install the project dependencies once, then generate the latest local flight data.

  1. 01

    Install dependencies

    Create and activate a virtual environment, then run:

    pip install -r requirements.txt
  2. 02

    Refresh and review

    Generate the latest data, then open an airport dashboard.

    python3 cmd/main.py

Operational focus

Why departures?

Departing passengers gather in the gate area, so scheduled departures are a useful signal for staffing and expected crowding. Arrivals do not represent that same passenger flow.
